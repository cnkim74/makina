# makina

성원마끼나(MAKKINA) 브랜드 웹사이트 프로젝트.
경북 안동 서후면에서 조사료(축산 사료) 작업기를 만드는 제조사의 공식 사이트입니다.

## 저장소 구조

```
docs/
  design/        디자인 시스템 원본 자료 (브랜드북, 토큰, 시안 HTML, 폰트 컨셉)
```

웹사이트 소스 코드는 아직 없습니다. 디자인 자료를 기준으로 페이지를 만들어 나갑니다.

## 시작하기

1. `docs/design/README.md`에서 자료 목록을 확인합니다.
2. `docs/design/brand-guide.md`를 읽고 브랜드 규칙을 파악합니다.
3. 시안은 `docs/design/components/*/preview.html`을 브라우저에서 바로 열어 볼 수 있습니다.
