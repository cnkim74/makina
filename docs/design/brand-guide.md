# 성원마끼나 MAKKINA

> **이름처럼 일하는 기계.**
> 경북 안동 서후면에서 조사료(축산 사료) 작업기를 만드는 장인 제조사의 브랜드 웹 디자인 시스템.
> 메인 화면 시안은 **Components → HomePage(데스크톱 1440) / HomePageMobile(390)** 에서 바로 볼 수 있습니다.

---

## 1. 브랜드가 말하는 방식

| 항목 | 내용 |
| --- | --- |
| 한 줄 | 베고, 모으고, 묶고, 감싸다. 조사료의 처음부터 끝까지. |
| 태그라인 | FORAGE MACHINERY · ANDONG |
| 톤 | 모던 · 묵직함 · 장인 제조사. 국내 농기계 기업 사이트(대동 등)의 익숙한 문법 위에, 현장 사진과 짧은 카피로 차이를 만든다. |
| 핵심 모티프 | **원형 베일 단면의 나선(Spiral)** — 로고 심볼에만 쓴다. 페이지 장식으로 반복하지 않는다. |
| 피할 것 | 디자이너 티 나는 장식: 섹션 번호·눈썹 라벨, 거대한 영문 숫자, 추상 도형, 다크/라이트 섹션 번갈아 쌓기. 사진이 주인공이고 UI는 뒤로 물러난다. |

**카피 원칙**
- 문장은 짧게, 동사로 끝낸다. "남김없이 벱니다", "고르게 모읍니다".
- 숫자는 글보다 크게 말한다. 마력·작업폭·RPM은 `spec-xl`로, 단위는 `spec-unit`으로 옆에 작게.
- 전화번호 **054-843-4000** 은 항상 눌리는 버튼이다. 텍스트로만 두지 않는다.
- 주 사용자(고령 농가)를 고려해 본문은 18px 아래로 내리지 않고, 버튼 높이는 56px 이상.

## 2. 컬러

### 메인
| 토큰 | HEX | 용도 |
| --- | --- | --- |
| `soil-black` 흙먹 | #1C1A17 | 메인 다크 배경, 라이트 섹션 헤드라인 |
| `hay-gold` 건초금 | #E0A526 | 브랜드 대표색 — 로고, 핵심 강조, 큰 숫자 |
| `straw-cream` 볏짚 | #F4EDDC | 라이트 배경, 다크 위 본문 글자 |

### 서브
| 토큰 | HEX | 용도 |
| --- | --- | --- |
| `field-brown` 논흙 | #4A3A2C | 다크 섹션 카드 배경 |
| `silage-green` 사일리지 | #5B7340 | 작물·친환경·성공 상태(면으로만) |
| `steel-gray` 강철 | #8C9196 | 스펙 라벨, 보조 텍스트(다크 위) |
| `wrap-white` 랩필름 | #FAFAF6 | 라이트 카드, 입력창 |

### 기능
| 토큰 | HEX | 용도 |
| --- | --- | --- |
| `signal-orange` 신호 | #E4572E | **전화 상담 CTA 전용**, 시즌 알림 배지 |
| `line` 경계선 | #D9CFB8 | 라이트 모드 구분선 |

**배색 비율** — 다크 섹션 `soil-black 60 : field-brown 25 : hay-gold 15`, 라이트 섹션 `straw-cream 70 : soil-black 20 : hay-gold 10`.

**규칙**
- `hay-gold` 위 글자는 반드시 `soil-black`. 흰 글자는 대비가 모자란다(2.1:1).
- `signal-orange` 위 글자는 `wrap-white`. 오렌지는 전화 CTA 외에 쓰지 않는다 — 페이지에서 오렌지가 보이면 "전화"라는 뜻이어야 한다.
- `silage-green` 은 작은 글자 색으로 쓰지 않는다(볏짚 위 3.6:1). 면·배지 배경으로만.
- 테마: 메인 화면은 다크(흙먹)로 열고, 제품·소모품 섹션은 라이트(볏짚)로 전환한다. 테마 토큰 `surface / surface-raised / ink / ink-muted / hairline` 이 전환을 담당한다.

## 3. 타이포그래피

| 역할 | 서체 | 어디에 | 비고 |
| --- | --- | --- | --- |
| 제목 | **지마켓 산스 Bold** | 섹션 제목, 제품명, GNB·탭·버튼 | 단단하고 묵직하게. 자간 -3%. |
| 목소리 | **카페24 동동** | 히어로 슬로건, 제품 캐치카피("한 번에, 세 가지."), 영상 자막, NEW·시즌 배지 | 사람이 말하는 한 줄에만. 한 화면에 한두 군데, 두 줄을 넘기지 않는다. 본문·버튼·숫자에는 절대 쓰지 않는다. |
| 본문 | **프리텐다드** | 본문, 메타 정보, 폼, 전화번호·숫자(Black) | 18px 이상, 줄간 1.65. |

세 서체의 관계 — 지마켓 산스가 뼈대, 프리텐다드가 살, 동동이 목소리. 동동이 많아지면 어린이 브랜드처럼 보이므로 슬로건과 캐치카피에서 멈춘다.

웹폰트 — 지마켓 산스·카페24 동동·프리텐다드 모두 무료 배포 서체다. 각 woff2 파일을 `fonts/`에 넣으면 미리보기에도 적용된다(지금 미리보기는 Noto Sans KR 대체 렌더링). 카페24 동동은 기본 굵기 하나뿐이니 Bold 처리하지 않는다.

스타일 스케일: `display-section 44` → `display-card 30` → `display-tab 19` / `accent-hero 64` → `accent-catch 24` → `accent-badge 15` / `body-lg 20` → `body 18` → `caption 15`, 숫자는 `spec-number 40`.

## 4. 로고

**심볼 「감기는 M」** — 원형 베일 단면처럼 선이 안쪽으로 3~4바퀴 감겨 들어가는 나선. 나선의 바깥 끝이 꺾이면서 M의 첫 획이 된다.
**워드마크** — 영문 `MAKKINA` 는 두 K를 칼날처럼 깎아 "베는 기계"를 표현. 국문 `성원마끼나` 는 하단·우측 보조 표기.

컬러 버전 ① Hay Gold 심볼 + Soil Black 워드마크(기본) ② 전체 Straw Cream(다크 배경) ③ 전체 Soil Black 단색(기계 각인·스티커).
로고는 기계 본체에 각인되므로 **단색 각인이 가능한 단순한 형태**를 지킨다. 최종 벡터 파일이 정해지면 `assets/Logo/`에 올린다 — 현재 시안의 심볼은 컨셉 드로잉이다.

## 5. 레이아웃 · 여백

- 검정 유틸 바(44) + 흙먹 GNB(88) 고정. 로고 좌, 메뉴 5개 중앙, 검색 우.
- 본문 바탕은 흰색. 사진 위에 흰 글자를 얹는 띠 섹션(마력 찾기, 고객지원)이 리듬을 만든다.
- 컨테이너 1,240px. 섹션 사이 110px. 모바일 좌우 20px.
- 탭·정렬·버튼은 **알약형(`radius-pill`)**, 카드와 사진은 각진 테두리 1px `#e5e5e5`.
- 우측 플로팅 원형 버튼 4개(구매 상담 · 소모품 주문 · 작업 영상 · 전화상담)가 모든 페이지를 따라다닌다. 전화상담만 흙먹, 나머지는 `signal-orange`.

## 6. 메인 화면 구성 (HomePage)

| # | 섹션 | 테마 | 핵심 |
| --- | --- | --- | --- |
| 1 | 히어로 | 사진 | 전면 현장 영상 루프, 좌하단 슬로건 "베고, 모으고, 묶고, 감싸다." + 슬라이드 번호 01–05, 우하단 흙먹 패널 "이름처럼 일하는 기계 → 작업기 보기" |
| 2 | 작업 흐름 | 흰색 | 번호 원형 5개를 선으로 이은 절차도. 활성 단계만 오렌지 |
| 3 | 대표 작업기 | 흰색 | 알약 탭(전체/베일러/모우어/…) + 흰 카드 3장(누끼 사진, 이름, 오렌지 카테고리, 한 줄 카피), NEW 리본 |
| 4 | 내 트랙터 마력으로 찾기 | 사진 띠 | 중앙 제목 + 알약 버튼 5개, 선택 시 연결 가능 작업기 한 줄 |
| 5 | 작업 영상 | 흰색 | 둥근 검색창 + 해시태그 + 정렬 알약 + 썸네일 3개(큰 재생 버튼, 자막형 제목) |
| 6 | 소모품 빠른 주문 | 흰색 | 네트·랩 카드 2장, 수량 스테퍼, "수확철 당일 출고" 안내 띠 |
| 7 | 고객지원 + 오시는 길 | 사진 띠 / 흰색 | "무엇을 도와드릴까요?" + 아코디언 5개(+) · 지도와 주소·전화·카톡 |

모바일(HomePageMobile)에는 **하단 고정 버튼 3개** — 전화 상담(오렌지) / 카톡 문의 / 소모품 주문 — 이 항상 따라온다.

시안의 사진·제품 실루엣은 자리표시다. 현장 영상, 누끼 제품 사진, 공장 사진이 오면 교체한다 — 이 디자인은 사진이 들어와야 완성된다.

## 7. 모션

| 시그니처 | 어디서 | 내용 |
| --- | --- | --- |
| 감기는 나선 | 로고 인트로 | 첫 방문 시 1.2초, 선이 바깥에서 안으로 감기며 로고 완성. 재방문 생략 |
| 베어지는 화면 | 히어로 | 스크롤 시작 시 수평 칼날 라인이 지나가고 화면이 위아래로 갈라진다 |
| 굴러가는 베일 | 작업 흐름 | 가로 스크롤에 맞춰 원형 베일 마커가 굴러 다음 단계로 |
| 빨려 드는 입자 | 블랙홀 상세 | 풀잎 입자가 나선을 그리며 제품 중심으로 |
| 회전 숫자 | 스펙 카운터 | 마력·작업폭·RPM이 드럼처럼 세로로 돌다 멈춤 |

**원칙** — 기본 0.4~0.6초, `cubic-bezier(0.22, 1, 0.36, 1)`. 페이지당 시그니처 모션 1개. OS "동작 줄이기"가 켜져 있으면 전부 정적 전환. 영상은 저용량 루프, 입자 모션은 저사양 기기에서 자동 해제.

## 8. 접근성 체크

- 본문 18px 이상, 버튼 56px 이상, 터치 타깃 48px 이상.
- 볏짚 위 흙먹 15:1, 흙먹 위 건초금 7.8:1, 흙먹 위 강철 5.3:1. 오렌지 위 랩필름은 3.5:1 — 그래서 전화 버튼 글자는 항상 18px Bold 이상(큰 글자 기준 3:1)으로 쓰고, 작은 글자를 오렌지 위에 올리지 않는다.
- 색만으로 상태를 말하지 않는다 — 활성 단계는 색 + 굵기 + 마커 위치.
