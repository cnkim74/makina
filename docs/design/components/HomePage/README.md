# HomePage

성원마끼나 메인 화면, 데스크톱 1440 시안. 국내 농기계 기업 사이트의 익숙한 구조(검정 헤더 · 전면 사진 히어로 · 알약 탭 · 흰 카드 · 우측 플로팅 상담 버튼)를 따르되, 카피와 컬러로 성원마끼나답게 만든다.

## 구성
1. 유틸 바 + GNB — 회사소개 · 작업기 · 소모품 · 고객지원 · 마끼나 스토리, 우측 검색.
2. 히어로 — 전면 영상, 좌하단 슬로건 + 슬라이드 번호(01–05, 진행 바 `hay-gold`), 우하단 흙먹 패널 "이름처럼 일하는 기계 → 작업기 보기".
3. 플로팅 버튼 — 구매 상담 · 소모품 주문 · 작업 영상 보기(`signal-orange`), 전화상담(흙먹). 말풍선 "작업기가 궁금하신가요?".
4. 조사료 작업 흐름 — 번호 원형 절차도(들판 → 1 베기 → 2 모으기 → 3 묶기 → 4 감싸기 → 5 소모품).
5. 대표 작업기 — 알약 탭, 흰 카드 3장(비무꼬 NEW · 블랙홀 · 모조리), "작업기 전체 보기".
6. 내 트랙터 마력으로 찾기 — 사진 띠, 알약 버튼 5개, 선택 결과 한 줄.
7. 작업 영상 — 검색창 · 해시태그 · 정렬 · 썸네일 3개(자막형 제목, 날짜).
8. 소모품 빠른 주문 — 네트 · 랩 카드, 수량 스테퍼, 당일 출고 안내.
9. 고객지원 — "무엇을 도와드릴까요?" 사진 띠 + 아코디언 5개.
10. 오시는 길 — 지도 + 주소 · 운영시간 · 전화 · 카톡 · 길찾기. 푸터.

## 교체할 자리표시
히어로 영상, 사진 띠 2곳, 영상 썸네일, 제품 누끼 사진(흰 배경), 지도(카카오맵 임베드), 사업자 정보·상세 주소·운영 시간.

## 소비자가 제공할 것
현장 영상·사진, 제품 사진, 제원표(마력 필터 매핑), 카카오톡 채널 링크, 지도 좌표, Paperlogy·Pretendard 웹폰트 파일.
