# HomePageMobile

메인 화면의 모바일(390) 시안. 데스크톱 구성을 한 열로 접고, 탭은 가로 스크롤, 작업 흐름은 번호 원형 5개 + 활성 단계 설명 박스로 줄인다.

## 하단 고정 버튼 3개
흰 도크(상단 1px 선, 그림자 `shadow-float`), 높이 54px 알약형:
- **전화 상담** — `signal-orange` 배경, 흰 글자, 가장 넓게. `tel:` 링크.
- **카톡 문의** — 카카오 노랑(#FAE100) 배경, 흙먹 글자.
- **소모품 주문** — 흙먹 배경, 흰 글자.

본문 17px 이상, 버튼 44px 이상. 플로팅 원형 버튼은 모바일에서 쓰지 않고 이 도크가 대신한다.
