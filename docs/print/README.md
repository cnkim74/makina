> **2026-10-29**: 4단 병풍 리플렛을 396×250mm(98·100·100·98)로 다시 짰다. 접는 선 확인용 `leaflet-4fold-folds.jpg`(빨간 점선 = 접는 선, 파란 점선 = 재단선).
> **2026-10-29**: A4 양면 전단 추가(4단 리플렛 원고 기준). 재단선 판·TrimBox 포함. 앞면 표지는 받은 사진(1920×1080, 수단그라스 예취)으로 바꾸고 가로형 칸(216×134mm)에 맞춰 약 205ppi. 원본(더 큰 사진·4K 영상)이 있으면 바꾸면 더 선명해진다. 나머지 이미지는 300ppi 이상.
> **2026-10-29 (2)**: HS봄바람체 2.1 파일을 받아 홈페이지와 인쇄물 전체(3단 리플렛 포함)에 적용. A4 전단 뒷면·4단 리플렛 라인업 판의 제품 이미지를 새 3D 렌더로 교체.

X배너는 실제 크기로 만들었고 사진은 실제 크기 기준 약 90dpi(배너 출력에 충분)다. 네 귀퉁이 40mm 안에는 글자를 두지 않았다.

4단 리플렛 PDF에는 TrimBox(재단 396×250)와 BleedBox(도련 402×256)를 적어 두었다. 재단선이 필요 없는 인쇄소는 `-print.pdf`, 재단선이 있는 파일을 받는 인쇄소는 `-print-cropmarks.pdf` 를 보낸다. 재단선·접지선은 레지스트레이션 색(CMYK 100/100/100/100)이다. 글은 재단선에서 10mm, 접는 선에서 8mm 안쪽에만 두었다. 총 잉크량은 어두운 바탕 약 280%, 가장 진한 곳 305%(사진 일부). 사진·도면은 실제 크기에서 모두 300ppi 이상(사진 300~1,300ppi), 로고는 800ppi 이상, 글자·워드마크는 벡터(아웃라인)라 해상도와 상관없다.

반투명 그라데이션은 CMYK 변환 때 사라지므로, 사진 위 그라데이션은 사진에 미리 합쳐 넣었다(2026-10-26 수정본).
